SPENDWISE — EXPENSE TRACKER (FATHIMA NOORAIN)

This project is built with plain HTML, CSS and JavaScript so it can run directly
through the VS Code Live Server extension. Node.js, npm, React and a build step
are NOT required.

HOW TO RUN
1. Extract Expense-Tracker-Live-Server.zip.
2. Open the extracted Expense-Tracker-Live-Server folder in Visual Studio Code.
3. Install the "Live Server" extension by Ritwick Dey if it is not already installed.
4. In VS Code Explorer, right-click index.html.
5. Select "Open with Live Server".
6. Your browser will open the website (usually http://127.0.0.1:5500).

FEATURES
- Dashboard with monthly spending, transaction count and daily average.
- Month selector with previous/next arrow navigation and comparison with the previous month.
- Add expenses defaults to the selected month; saving an expense updates the selected month and charts.
- Monthly History page with month/year selection, previous-month comparison, category-wise breakdown and full expense records.
- Export the selected month's records to a separate CSV file.
- Category donut chart and a complete spending trend covering every month between the first and latest recorded expense. The selected month is highlighted; adding, editing or deleting expenses redraws the chart.
- Add, edit and delete expenses with validation.
- Search, category filter and month filter for transactions.
- Seeded categories: Food, Transport, Bills, Shopping, Entertainment and Other.
- Add, rename and recolour custom categories.
- Prevent deletion of a category while expenses are assigned to it.
- Export all expenses to CSV.
- Data is saved in browser localStorage and remains after refresh in the same browser.

IMPORTANT
- Initial demo expenses are included to make the dashboard charts visible.
- All data is stored locally in the browser on this device. Clearing browser site data
  may erase it. CSV export is provided as a backup.
- This is a front-end local website; it does not include online accounts or cloud sync.
- Google Fonts are optional and load from the internet; the app itself works without them.
